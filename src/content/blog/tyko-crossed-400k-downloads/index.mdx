Apparently, people have been downloading my Kubernetes operator.

[Typesense Operator (TyKO)](https://github.com/akyriako/typesense-operator) has officially crossed **400,000 Helm chart downloads** 
through GitHub Releases. **Four hundred thousand**.

<GithubCard repo='akyriako/typesense-operator' />

Not bad for an open-source side project that started with the simple idea of making [Typesense](https://typesense.org/) a little less painful to run on Kubernetes. Because apparently Kubernetes didn't have enough operators already.

Now, before anyone gets too excited, downloads aren't necessarily unique installations. This is Kubernetes, after all. Half the ecosystem is probably a CI pipeline downloading the same thing every five minutes.

Still, seeing that number on a project I've built and maintained is pretty bloody satisfying.

To everyone who's downloaded TyKO, tried it out, reported a bug, or contributed along the way: **cheers, mate.** Genuinely appreciated.

And to whoever keeps downloading `v0.3.5` like there's no tomorrow: I'd love to know what you're running over there.
